# manual_car_control 全部功能说明

当前工程主要使用 `platformio.ini` 里的 `manual_car_control` 环境。  
本版本增加了模式输入捕获脚 `PC7 / TIM8_CH2`。默认 1000us 为手动模式，2000us 为自动模式。  
手动模式下保留遥控小车功能；切到自动模式后执行一次“3 行 x 4 颗”的蛇形路线自动种植流程，总共种植 12 颗苗。执行完第 12 颗后进入安全停止状态，所有执行机构关闭。

## 烧写命令

```powershell
& "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe" run -e manual_car_control -t upload
```

## 蛇形路线

自动流程只有在 `PC7` 模式输入处于自动范围时启动。

1. 第 1 行：种第 1、2、3、4 颗。
2. 第 4 颗完成后：前进 2 秒，右转 4 秒，前进 2 秒，右转 5 秒，前进 2 秒；右转时两侧轮子同时动作，一侧正转、另一侧反转。
3. 第 2 行：种第 5、6、7、8 颗，方向与第 1 行相反。
4. 第 8 颗完成后：前进 2 秒，左转 4 秒，前进 2 秒，左转 5 秒，前进 2 秒；左转时两侧轮子同时动作，一侧反转、另一侧正转。
5. 第 3 行：种第 9、10、11、12 颗。
6. 第 12 颗完成后：小车、电钻、移动电钻、水泵、覆土、送苗、太阳能板全部停止。

## 单颗苗动作

函数：`PlantOneSeedling(seed_index)`

1. 钻孔：
   - 移动电钻向下 8 秒。
   - 下移 0 到 5 秒：电钻关闭。
   - 下移 5 到 8 秒：电钻开启。
   - 下移结束后移动电钻停止，原地停 2 秒，电钻保持开启。
   - 移动电钻向上 8 秒。
   - 上移 0 到 4 秒：电钻开启。
   - 上移 4 到 8 秒：电钻关闭。
   - 最后移动电钻停止，电钻关闭。
2. 小车前进 0.5 秒。
3. PB0 送苗装置走一步。
4. 覆土 PG2/PG3 伸出 10 秒，停 1 秒，缩回 10 秒，停止。
5. 水泵 PE5 开启 3 秒后关闭。
6. 种完后的移动：
   - 第 4、8、12 颗不执行普通前进 5 秒。
   - 第 4 颗执行右转换行。
   - 第 8 颗执行左转换行。
   - 第 12 颗直接全部停止。
   - 其他颗完成后前进 1 秒到下一颗位置。

## 已停用的旧流程

- 旧的 3 轮 x 3 组流程。
- IMU 自动换行。
- 传送带正转/反转流程。
- 旧送苗正转 7 秒、反转 28 秒收尾。
- 旧水泵 10 秒循环。
- 旧移动机构前进 8 秒、后退 8 秒循环。
- PG2/PG3 和 PG4/PG5 同步动作的 cover_4pin 自动循环。

## 模式输入说明

| PC7 输入脉宽 | 判定模式 | 行为 |
| --- | --- | --- |
| 无信号或小于等于 1300us | 手动模式 | 小车遥控可用，自动流程不启动 |
| 1300us 到 1700us | 保持上一状态 | 用作防抖/过渡区 |
| 大于等于 1700us | 自动模式 | 启动一次 12 颗蛇形自动种植 |

自动流程运行中，如果 PC7 从自动范围切回手动范围，会立即执行 `ManualCar_AllStop()` 并退出自动流程。  
自动流程完整跑完后，如果 PC7 一直保持自动档，不会重复启动；需要先切回手动档，再切到自动档，才会开始下一轮。

## 手动模式电钻控制

新增 `PB14 / TIM12_CH1` 输入捕获，只在手动模式下生效：

| PB14 输入脉宽 | 行为 |
| --- | --- |
| 无信号或小于等于 1250us | 移动电钻停止，电钻关闭，并刷新/解锁下一轮测试 |
| 大于 1250us 且小于等于 1750us | 移动电钻向下，电钻开启 |
| 大于 1750us | 移动电钻向上，电钻开启 |

状态逻辑：
- 从 1000us 切到 1500us 左右，移动电钻向下并开启电钻。
- 再从 1500us 切到 2000us 左右，移动电钻向上并保持电钻开启。
- 回到 1000us 后停止并关闭电钻，同时允许下一轮测试。

方向沿用自动流程约定：`FORWARD` 为下移，`REVERSE` 为上移。

## 手动模式覆土单独测试

新增 `PE6 / EXTI6` 输入捕获，只在手动模式下生效：

| PE6 输入脉宽 | 行为 |
| --- | --- |
| 无信号或小于等于 1250us | 覆土停止，并刷新/解锁下一轮测试 |
| 大于 1250us 且小于 1750us | 覆土向下移动 |
| 大于等于 1750us | 覆土向上移动 |

状态逻辑：
- 从 1000us 切到 1500us 左右，覆土向下移动。
- 再从 1500us 切到 2000us 左右，覆土向上移动。
- 回到 1000us 后停止，并允许下一轮单独测试。

方向约定：覆土向下使用 PG2/PG3 的伸出动作，覆土向上使用 PG2/PG3 的缩回动作。

## 手动模式送苗/水泵单独测试

新增 `PF11 / EXTI` 输入捕获，只在手动模式下生效：

| PF11 输入脉宽 | 行为 |
| --- | --- |
| 1500us 左右 | 不动，并刷新/解锁下一轮测试 |
| 2000us 左右 | PB0 送苗装置持续按步循环转动 |
| 1000us 左右 | PE5 水泵持续开启 |

状态逻辑：
- 从 1500us 切到 2000us 左右，PB0 送苗装置开始持续按步循环。
- 信号保持在 2000us 时，送苗按“125 个低脉冲为一步，低 1000us、释放 4000us，步间停 1 秒”的节奏循环。
- 回到 1500us 左右后，送苗停止，并刷新/解锁下一轮。
- 从 1500us 切到 1000us 左右，PE5 水泵持续开启。
- 信号保持在 1000us 时，水泵保持持续开启。
- 回到 1500us 左右后，水泵关闭，并刷新/解锁下一轮。

## 安全停止

自动流程结束后会调用 `ManualCar_AllStop()`：

- 小车停止。
- PC10 电钻继电器关闭。
- PC11/PC12 移动电钻停止。
- PE5 水泵关闭。
- PG2/PG3 覆土停止。
- PB0 送苗脉冲停止并释放为高电平。
- PG4/PG5 太阳能板停止。
