# 自动速度档位调节说明

本文记录当前已经合入并烧写测试的 `manual_car_control` 自动行驶速度档位功能。

## 当前版本状态

- 程序环境：`manual_car_control`
- 已烧写到板子：是
- 自动行驶默认速度：50% 占空比
- 速度最低限制：10% 占空比
- 速度最高限制：90% 占空比
- LCD 显示：白色背景，黑色大数字，只显示当前档位 `1` 到 `9`

## 档位对应关系

| LCD 显示 | 自动行驶占空比 |
| --- | --- |
| 1 | 10% |
| 2 | 20% |
| 3 | 30% |
| 4 | 40% |
| 5 | 50% |
| 6 | 60% |
| 7 | 70% |
| 8 | 80% |
| 9 | 90% |

默认上电后显示 `5`。

## PA8 模式选择

| PA8 输入脉宽 | 当前行为 |
| --- | --- |
| 无信号或 `<=1300us` | 空闲，全停 |
| `1300us ~ 1700us` | 正常手动遥控小车和移苗机构 |
| `>1700us` | 自动速度设置模式，小车强制停止，只允许调速度档位 |

注意：在 `PA8 > 1700us` 时，小车不会响应遥控移动，这是为了避免调速度时车跟着动。

## PC6 调档规则

在 `PA8 > 1700us` 的自动速度设置模式下，`PC6` 不再当连续油门使用，而是当加减档开关。

| PC6 动作 | 结果 |
| --- | --- |
| 回到 `1300us ~ 1700us` | 重新允许下一次加减档 |
| 从中位推到 `>1750us` | 档位加 1，也就是占空比加 10% |
| 从中位拉到 `<1250us` | 档位减 1，也就是占空比减 10% |

每次加减后必须先回到中位区，下一次推高或拉低才会再次计数。长时间保持高位或低位不会连续加减。

## 自动行驶使用方式

自动流程中的小车前进、左转、右转都使用当前保存的自动速度档位。

手动摇杆遥控小车仍然使用自己的差速 PWM 逻辑：

- 摇杆中位死区内：0%
- 刚离开死区：10%
- 推到底：90%

所以自动速度档位只影响自动流程，不改变手动摇杆的连续调速手感。

## 当前烧写命令

```powershell
& "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe" run -e manual_car_control -t upload
```
